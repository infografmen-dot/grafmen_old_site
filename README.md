# Grafmen.com — Statyczna Strona Internetowa (HTML5 / CSS3 / Vanilla JS)

Oficjalny statyczny serwis internetowy marki **GRAFMEN** (Krzysztof Krawczyk — Grafik komputerowy i Freelancer).

## 🚀 Technologie
- **HTML5** (Semantyczny, czystykod, 22 strony docelowe)
- **CSS3** (Vanilla CSS, Custom Properties, Dark Mode `#0F0F10`, `#18181A`, `#FF5A00`, typografia `Outfit`)
- **Vanilla JavaScript** (Lekka nawigacja mobilna, stany ARIA, walidacja formularza)
- **FormSubmit** (`https://formsubmit.co/info@grafmen.com`) — Obsługa formularza kontaktowego
- **Notion** — Zewnętrzne formularze briefów dla poszczególnych usług

## 📂 Architektura Projektu
- `index.html` — Strona główna
- `portfolio.html` — Statyczna siatka 16 prac portfolio
- `o-mnie.html` — Strona o mnie i warsztat narzędziowy
- `oferta.html` — Oferta usług i linki do briefów
- `kontakt.html` — Formularz kontaktowy
- `polityka-prywatnosci.html` — Polityka prywatności RODO
- `portfolio/` — 16 dedykowanych podstron prac w portfolio
- `assets/css/main.css` — Główny arkusz stylów CSS
- `assets/js/main.js` — Skrypt Vanilla JS
- `assets/images/` — Wyselekcjonowane pliki graficzne (tools, services, portfolio)
- `sitemap.xml` & `robots.txt` — Pliki konfiguracyjne SEO

## 🌐 Hosting & Wdrożenie
Strona jest w 100% statyczna i nie wymaga PHP, bazy danych ani serwera Node.js. Może zostać opublikowana na **GitHub Pages** lub **Vercel**.
